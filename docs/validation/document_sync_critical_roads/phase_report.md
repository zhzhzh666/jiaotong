# 龙岗关键道路识别与治理优化：初版验收

本轮按[实施规划](LONGGANG_CRITICAL_ROADS_PLAN.md)完成数据冻结、12候选道路反事实筛查、四点治理策略比较和分预算清单。全区动态验证及工程资料补充仍待完成。本轮未运行新的SUMO、重算水文或改动Word/PPT。

## 实际计算与数据范围

- 龙岗不含大鹏。451,801条源有向弧、307,426个源节点，串联收缩为97,030条走廊、47,498个端点；保留原弧和有向平行边身份。
- 完整483×483合成平峰OD，413个分区接入（401个区内分区和12个外部网关）；未接入、正常不可达和区内需求不混入新增洪水损失。静态分析不做目的地抽样，不考虑拥堵反馈、队列和信号。
- 1.0倍雨量峰值至少0.05 m的1,154个地面源要素构成初筛池；按峰值水深、正常最短路流量、抽样加权介数及暴露×流量取并集并补足12个候选。逐一评估正常中断及三档雨量单道路恢复，共48个反事实，加无雨/三暴雨基准共52次静态求解。
- 加权介数在走廊端点图上均匀抽样32个起点估计，平行同权最短边均分；不是307,426节点原图的全介数。正常流量是完整OD单最短路AON的最大有向弧流量，非实测或拥堵均衡流量。
- 各雨量取第一处同时封闭源要素数量最大的真实快照：0.7倍为2023-09-10 10:00、1.0倍为15:30、1.3倍为16:30，北京时间。均用相同合成平峰OD作受控比较，不声称还原该时刻实际车流。

静态指标为 `Σq×min(max(t−t0,0),7200)/3600`，单位veh·h/h。正常可达、灾后不可达的需求计7200秒增量；正常已不可达另记。三快照恢复收益等权平均排序，不代表实际灾害概率、实际延误或全过程韧性R。

道路单位为源要素及其已映射有向弧；不是整条命名道路。OSM ID、source_feature_position和source_feature_id均保留，原始中文名称编码异常时不猜名称。未知桥隧及覆盖外水深在交通中假设正常。

## 四点治理与预算对照

独立重放45份既有动态情景账本，重构15个组合的最坏广义成本增量及未完成量，再比较不治理、随机10种子、水深/流量/介数优先、静态道路筛查优先、边际收益贪心和穷举。所有策略查询已有组合真实结果；没有把单点收益相加当组合收益。

| 相对预算 | 预算内最优组合 | 最坏相对无雨广义成本增量降低 |
| ---: | --- | ---: |
| 0 | 不治理 | 0 |
| 1.8225 | S3（mask8） | 5.4498% |
| 3.6450 | S0、S3（mask9） | 9.8871% |
| 5.4675 | S0、S1、S3（mask11） | 11.2577% |

四个预算下边际收益贪心均与四点穷举最优一致。水深、流量和静态道路筛查优先在本次四点候选中也得到相同顺序，**本轮没有证明贪心优于这些策略**。介数优先在单点预算时不同。最优性仅限当前四点、最多三处和冻结参数。

治理收益引用既有120小时、每起点2层目的地抽样比例点队列；其无雨参考已过饱和。原mask9在4层同组合1.3倍雨量中收益为5.7642%，原2层为9.8871%，排序未做全组合收敛。圆形750 m内增加4 mm/h损失能力和相对成本是研究假设，不能作为工程收益预测。诊断单道路归零与水文重算后的排水点治理是不同决策单元，关联表不是工程汇水区认证。
