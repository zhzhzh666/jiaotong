# RTX4090 五场景仿真迁移包

目标机按用户2026-11-19最新配置：ASUS E500 G9、Intel Core i9-14900K（32逻辑线程）、128 GiB RAM、RTX4090（用户说明）、2 TB磁盘、Ubuntu22.04.5 LTS x86_64。

本包是完整迁移包，可以独立解压，不需要旧5090压缩包。包含已冻结龙岗路网、OD、ERA5/DSM/WorldCover积水与治理数据、已审计无雨基准和源码。5%合成需求、4小时、seed42、单任务、关闭GUI；先在新机器测量性能再扩规模。

当前“仿真训练”可实际执行的是SUMO情景仿真和现有参数/治理实验；没有深度学习训练器，也没有已实现的Gawron/SDTA迭代分配。现有求解器使用CPU，4090不直接加速SUMO。PPT模型的关键道路识别与治理扩展流程另行交付，不能将本包五场景当作该流程已完成。

## 1. 复制并解压

将同名`.tar.gz`和`.tar.gz.sha256`复制到Ubuntu同一目录，使用一个新的空项目目录：

```bash
sha256sum -c jiaotong_ubuntu4090_simulation_20261119.tar.gz.sha256
mkdir -p "$HOME/projects/jiaotong_4090"
tar -xzf jiaotong_ubuntu4090_simulation_20261119.tar.gz -C "$HOME/projects/jiaotong_4090"
cd "$HOME/projects/jiaotong_4090"
python3 scripts/migrate_5090.py verify
```

建议至少15 GiB可用空间供环境和短期结果，长期实验预留100 GiB以上。原有`migrate_5090.py`、`run_5090.py`等名称为兼容旧工程保留；目标硬件以`migration/target_hardware.json`为准，不要求5090显卡。

## 2. 安装与实测

先安装Linux版Miniforge/Miniconda并确保当前终端能找到`conda`。环境安装需要联网；本包不含Linux离线wheel仓库。

```bash
bash migration/bootstrap_ubuntu.sh
conda activate "$PWD/.conda-env"
python scripts/check_4090.py --smoke
python scripts/run_4090.py --cases dry
```

安装脚本创建独立`.conda-env`，Python3.11、SUMO/sumolib/traci1.28.0。不可复制Windows环境。系统动态库诊断和安装示例见`migration/README_迁移与回传.md`。不需要为当前CPU求解器安装CUDA Toolkit。

## 3. 补跑五组对照

无雨基准结束后复用同一准备路网和出行计划：

```bash
RUN="$(cat results/remote_runs/LATEST.txt)"
python scripts/run_4090.py --resume "$RUN" --cases dry rain_departure rain_rolling governed_departure governed_rolling
```

五组分别为无雨、暴雨出发选路、暴雨途中滚动改道、S0/S3治理后出发选路、S0/S3治理后滚动改道。后四组使用1.3倍ERA5雨量对应的冻结积水，滚动检查间隔300秒。

从头独立跑五组可用`bash migration/run_4090_five_cases.sh`，推荐在tmux内运行。一次先跑1个任务；32线程不代表单个SUMO能32倍加速。记录逐仿真小时耗时和Python+SUMO进程RSS后，再决定并发。128 GiB RAM可容纳更多实验，但本包不自动启动32个任务。

仅支持情景边界恢复。若某组中途失败，保留现场，另开新run；没有中途仿真状态恢复。每次新实验保存独立ID、源码和输入SHA，不能覆盖历史manifest。

## 4. 打包返回本机

运行完成、文件停止写入后：

```bash
RUN="$(cat results/remote_runs/LATEST.txt)"
python scripts/migrate_5090.py export --run "$RUN" --out "$HOME/jiaotong_4090_return.tar.gz"
```

压缩包与同名SHA文件一起带回Windows。在`C:\Users\zh\Desktop\git\jiaotong`执行：

```powershell
.\.conda-env\python.exe scripts\migrate_5090.py receive D:\transfer\jiaotong_4090_return.tar.gz
```

自动逐文件校验并导入`results/imported/新标识/`，在`results/analysis/同一标识/`生成`REPORT.md`、`comparison.csv`和`analysis.json`；保留原始轨迹、路线、资源记录、配置、源码与必要输入，不覆盖本机历史结果。

包内已有旧片区三维网页回放；新全区仿真结果不会自动替换旧网页。数据仍属未标定合成研究情景，不应乘20外推全需求或解释为真实工程收益预测。
