# 龙岗降雨数据可获得性与已取得样例

核查日期：2026-11-18。用途：为B方案（地形＋历史降雨＋简化地表汇流）寻找降雨输入。本轮只核查数据并保存样例，未实施B或C模型。

## 结论

找到了可获取的历史降雨数据，并已实际取回一个龙岗附近网格的72条逐小时ERA5记录。该记录是再分析估计，不是龙岗雨量站原始观测，不能视为全区平均雨量或街道暴雨实测值。深圳官方自动站是优先的观测来源，但本轮尚未取回可核验的历史数值；NASA IMERG是已确认的半小时卫星降雨来源，本轮未下载其历史文件。

## 实际取回的样例

- [浏览器返回JSON文本快照](validation/rainfall/20261118_era5_sample.json)：保存可见API响应文本，新增文件末尾换行，不声称是HTTP传输原始字节归档。
- 请求位置：WGS84纬度22.72、经度114.25，仅用来验证龙岗附近的数据可获取性；不是已核实的雨量站坐标。
- 返回网格中心：纬度22.75、经度114.25；返回elevation=42 m是气象接口元数据，不作为内涝DEM。
- [实际请求](https://archive-api.open-meteo.com/v1/archive?latitude=22.72&longitude=114.25&start_date=2023-09-07&end_date=2023-09-09&hourly=precipitation&models=era5&timezone=Asia%2FShanghai)。按接口文档亦可追加format=csv下载，但本轮未单独验证CSV下载。
- 标记时刻：2023-09-07 00:00—2023-09-09 23:00，北京时间；共72条连续小时记录，0缺值，全部非负。
- 单位：mm；每条对应前一小时累计。例如2023-09-08 15:00对应14:00—15:00，数值5.4 mm，是这份样例的最大1小时量。
- 72个记录所覆盖区间合计115.6 mm。首条包含9月6日23:00—7日00:00，末条为9月9日22:00—23:00，因此不能称为9月7—9日完整三个自然日总量。
- 该合计与峰值都只描述此ERA5网格及上述区间，不能称为龙岗实测暴雨总量或峰值；本轮没有与同位置同时间的站点观测比较。

数据署名：[Weather data by Open-Meteo.com](https://open-meteo.com/)，ERA5来源为Copernicus Climate Change Service/ECMWF，经Open-Meteo提供。[Open-Meteo许可页](https://open-meteo.com/en/licence)明确API数据按[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)提供，须署名、链接许可并说明变更；该页亦链接Copernicus来源许可。此处仅存储响应文本和派生核验摘要，没有修改雨量值。免费接口文档显示非商业使用及每日少于10,000次调用限制；数据许可与服务调用条件应分别遵守。

推荐引用：Zippenfenig (2023), Open-Meteo.com Weather API, DOI：[10.5281/zenodo.7970649](https://doi.org/10.5281/zenodo.7970649)；Hersbach et al., ERA5 hourly data on single levels, DOI：[10.24381/cds.adbb2d47](https://doi.org/10.24381/cds.adbb2d47)。

## 接入B方案的步骤（尚未执行）

1. 确定暴雨事件及模拟时窗，保留雨前初始条件与雨后退水时间，下载完整时窗，不能将本样例直接当作已选定的标定事件。
2. 优先取得研究区及上游的逐时或5—10分钟站点雨量，核实站号、位置、时区、累计口径、缺测与质量标记；只有日雨量或新闻中的事件总量不能恢复历史峰形。
3. 将IMERG或ERA5网格按汇水区面积加权，保留源网格尺度；多次请求落入同一网格不能当作多个独立站。站点插值或偏差订正需观测支撑，并保留独立验证资料。
4. 按时间区间重叠守恒转换成模型雨量/雨强：m/s = mm ÷1000 ÷时段秒数。逐小时数据若分成15分钟，可假设各15分钟分配四分之一小时雨量，但必须标明小时内均匀假设；这不会产生真实的15分钟峰值信息。
5. 先完成降雨输入核验，再建立地形驱动的侧向汇流、蓄水、入渗与假设排水；检查水量守恒和参数敏感性。现有30 m DSM的微地形局限仍存在，不能因取得降雨就宣布道路尺度内涝预测已验证。

既有合成暴雨包、OD包、配置和历史manifest不变；未重跑内涝、交通分配或韧性。样例仅证明存在可实际获取的数据路径。
