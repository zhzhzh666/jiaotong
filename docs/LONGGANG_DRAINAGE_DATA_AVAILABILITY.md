# 龙岗真实排水管网公开数据核查

核查日期：2026-11-18。范围：龙岗区，不含大鹏。任务：核实能否取得用于 SWMM 与二维地表水动力耦合的真实排水数据。

## 结论

本轮未核实到可直接下载、覆盖研究区且字段完整的真实雨水管网数据。此结论只表示本轮检索未取得数据，不表示数据不存在，也不表示所有管网资料均不公开。

已核实的官方公开内容是全市排水汇总统计、排水设施数据质检工具附件以及正式信息申请指南。深圳开放数据平台的详情与检索页未正常呈现数据内容，不能据页面空白认定没有数据。龙岗工程新闻只获得标题/搜索摘要，未核实到工程图纸或管网附件。

没有下载真实管线或检查井数据，没有确认此类数据的许可，没有运行 SWMM 或二维求解器。现有合成道路低点与动态蓄水桶结果继续保留，不能称为 C 方案结果。

深圳市水务局办公室受理政府信息公开申请。指南公布联系电话0755-83072860，办公地址为深圳市福田区莲花路1098号水源大厦；电话适合咨询，指南明确不直接受理电子邮件、电话或短信申请。

指南列出的[互联网申请入口](https://ysqgk.gd.gov.cn/755019/choice)及[申请表](https://swj.sz.gov.cn/attachment/1/1325/1325796/12310236.doc)可供申请人使用。本轮只读取指南，未访问填写或提交申请。指南要求真实申请人资料和身份证明；不能由公开检索直接代替这一手续。通常20个工作日内答复，符合规定时可延长不超过20个工作日；这是答复期限，不是承诺交付数据的期限。

优先申请已有资料及其数据字典、版本和使用条件。若市水务局不是具体资料保存机关，可请求告知保存机关/查询渠道；龙岗区水务主管部门、设施运维单位及工程资料持有方是后续咨询方向，本轮未核实这些单位各自的库存或承诺。

## C 方案需要申请与检查的字段

| 对象 | 所需已有资料 | 缺失影响 |
| --- | --- | --- |
| 雨水管/渠 | 唯一ID、线几何、起终节点ID、长度、断面形状及尺寸、材质/糙率依据、上下游管底高程、雨污类型、现状/规划/废弃状态 | 决定连接、流向、过流能力和压力水头；不能用道路中心线直接替代 |
| 检查井 | 唯一ID、坐标、井底及井盖高程、井深/截面、连接管线、溢流与地表交换位置 | 决定管网蓄水、溢流及二维交换 |
| 雨水口与连接支管 | 位置、接入节点、入口尺寸/形式、连接关系或进水能力依据 | 决定地表进水和反涌通量 |
| 排口、河道、泵闸 | 位置、连接节点、底高程、边界水位过程；泵曲线、闸门/控制规则（如有） | 决定下游顶托、泵排与外边界 |
| 元数据 | 坐标系、垂直基准、单位、测绘日期、精度、覆盖范围、数据字典、使用/再发布条件 | 避免几何、高程和版本错配；取得数据不自动意味着可上传GitHub |
| 二维模型补充资料 | 适合街道路缘与微地形的裸地DTM、建筑/道路障碍物、土地覆盖/入渗、短历时降雨、积水/流量校准记录 | 管网到位后仍需这些资料；现有约30 m DSM不能视为已满足精细内涝地形要求 |

优先索取可提供的原生格式（如GDB/SHP/GeoPackage/CAD及属性表，或已有SWMM INP），而不要求主管部门额外加工模型。二维子域和边界应按水力联系确定，不能简单在行政边界截断管线。

## 可复制的申请内容草案（未提交）

> 申请获取贵机关已保存的、龙岗区（不含大鹏新区）现状雨水及合流排水设施空间数据或相应普查/竣工成果，以及随附数据字典、测绘日期、坐标和高程基准说明。重点包括管渠线位与编号、起终节点、断面尺寸、上下游管底高程，检查井/雨水口/排口的位置、高程及连接关系，以及已有泵闸资料。用于暴雨内涝与交通影响研究，希望按现有电子格式提供，并告知使用和再发布条件。若部分内容不能提供，请依法说明可提供范围；若非贵机关保存，请告知保存机关或查询途径。此申请不要求额外测绘或加工建模。

如全区资料无法提供，可再按已确定的一个完整排水分区申请局部已有成果；不得把局部数据外推为全龙岗实测管网。

## 取得资料后的实施步骤（计划，尚未执行）

1. 原件只读归档并记录来源、许可、版本和SHA；核对空间范围、坐标/高程基准及现状类型。
2. 检查管井拓扑、管底高程、断面与出口边界；列出缺失值，实测与估计字段分别标记。
3. 选择数据完整的排水分区，建立并单独验证SWMM降雨径流与一维管网模型。
4. 构建裸地地形与二维网格，设置建筑、路缘、入渗和边界；独立检验地表流与干湿界面。
5. 通过雨水口/检查井设置双向交换，检查每个耦合步的质量守恒、时间步稳定性和溢流回灌，避免重复扣水。
6. 用历史降雨和独立积水/流量记录标定及验证，输出道路水深时序后再连接交通模块；新结果单独生成run_id，不覆盖现有合成情景。

本轮只更新数据可获得性说明，未修改模型代码/配置，未生成新仿真包，也未重跑既有测试或仿真。
