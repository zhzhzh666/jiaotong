# 龙岗动态路径与 SUMO 3D：片区试验结果

日期：2026-11-19。主运行 `20261118T175153_sumo_492a503a`，软件SUMO 1.28.0。范围是S0附近3 km×3 km工作域，包含周边连接道路，不代表全龙岗。

## 规模与设置

- 4,969条源有向弧、2,938个节点，源弧ID与SUMO边集合一致；每方向一条有效车道、优先权交叉口，车道及信号未标定。
- 从483×483完整合成OD的正常最短路径提取18,912个连续片区访问条目，保留出入和穿越交通；再进入视作另一访问。边界外改道不会反馈改变进入位置。
- 种子42、5%物理需求、Poisson车辆数，五组同用3,588辆计划；不是826个抽样OD对直接加载，也不能将微观结果乘20作为全需求结果。
- 北京时间2023-09-10 10:00—14:00，空网络开始，前3小时出发、末1小时继续处理已有车辆；取窗依据是无治理积水关闭弧数首次峰值，未使用交通收益筛选。
- 1秒仿真及安全检查、60秒到期发车尝试及输出、300秒滚动路线、900秒积水更新；只用当前状态，不提前读未来水深。
- 复用此前mask0/mask9在1.3倍雨量下的水深；没有新算水文或重新优化治理。

五组系统占用时间分别为907,534、24,270,030、24,270,030、21,176,262、21,176,262 veh·s；含7200秒未完成惩罚的广义成本分别为907,534、43,789,230、43,789,230、38,153,862、38,153,862 veh·s。右端点累计包含发车尝试间隔导致的外部等待，不能用完成者平均时长替代系统评价。

## 独立核验

171项测试通过、56条既有Rasterio/Affine弃用警告，pip check无冲突。独立审计验证12项源码/输入SHA、4,969条源弧、3,588条计划路径、168,946个道路水深值、五组完整车辆账本与全部系统耗时积分。五组车辆守恒误差均为0，自动传送与碰撞车辆事件均为0。

另用独立合成菱形路网实际关闭b边，将在途车辆从 `a b b2 d` 改到 `a c c2 d`，到达1辆、自动传送0。它验证控制器改道接口，不能当作龙岗实测或收益。

容量代理未校准。primary饱和单路段中，无积水、0.10 m、0.20 m参考容量1600/1200/800 veh/h，对应SUMO实际出流1338/1026/426 veh/h，偏差约−16.38%/−14.50%/−46.75%。当前tau代理不能称作宏观容量的精确等价实现。
