- 从准备开始的五组合计，常规外推约2.82小时；按可变运行时间两倍安排日程，建议预留约5.63小时。
- 本次无雨已完成，后续四组追加运行常规外推约2.54小时，两倍常规预算的剩余预留约5.35小时。
- 另列“全部有效车辆在所有滚动时点始终活跃”的极端压力外推：五组约16.03小时、追加四组约15.75小时。该假设连尚未出发车辆也纳入潜在查询数，刻意偏保守，不作为正常预期。

外推叠加实际道路控制写入量及滚动查询估计。常规借用无雨活跃车辆数；日程预留是两倍常规可变计算时间；极端压力项另采用两倍无雨交通耗时和全部车辆/全部时点的查询数。它们不是置信区间或保证上界；湿情景车辆数量、阻断查询、缓存、排队和内存换页均可能改变耗时。
