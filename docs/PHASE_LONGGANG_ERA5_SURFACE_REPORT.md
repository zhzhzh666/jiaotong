# 龙岗 ERA5 B方案阶段报告

用户选择ERA5/Open-Meteo作为降雨源后，完成数据获取、地形汇流原型运行与数值审计。本阶段是B方案简化原型，不是已校准历史内涝重建。

## 数据与范围

- 时间：北京时间2023-09-06 00:00至09-11 00:00，共120个完整小时；每条ERA5降水对应前一小时累计。
- 获取9个不同的0.25°网格，1,080条有效雨量；主域使用6个、龙岗面积加权使用4个。区内累计180.100249 mm，最大面积平均1小时量5.964334 mm。不是雨量站观测，不假设各网格在统计上相互独立。
- 龙岗（不含大鹏）386.957601 km²；30 m DSM平均至150 m，主域239×280=66,920格，行政边界外扩5 km矩形，外围为无外来流入的开放出口；10 km外扩做敏感性检查，不代表上游汇水区完整认证。
- 33,597个既有地面道路采样位置映射到8,530个模型网格；6,848条地面源线有估计值，952条桥隧等保持NaN，保留86,807条推定OD图有向弧的原ID映射。

## 运行结果

8组参数、481个15分钟输出端点。基准道路样点最大估计深度1.030854 m；同时超过0.15 m的源线最多45条，达到0.30 m的最多2条。这些是模型暴露统计，不代表45条实测积水道路或真实封路。区内估计深度>0.15 m同时最大面积0.608831 km²，各时刻峰值并集面积0.676331 km²。

合并损失假设2/4/8 mm/h时，道路样点最大估计深度4.098790/1.030854/0.011329 m；雨量0.7/1/1.3倍为0.165155/1.030854/2.498684 m。输出强烈依赖未标定假设，不能据此确定真实积水深度。

全计算域基准累计降雨266202702.000 m³，合并损失265470787.331 m³，边界排出119605.938 m³，末端蓄水612308.731 m³。损失占降雨约99.725%，反映参数设定；不是测得排水效率。时窗末端仍有蓄水，不能宣称全部退水。

## 验证与局限

151项测试通过（56条既有Rasterio/Affine待弃用警告），pip check无冲突。10项运行检查通过。独立核验1,080条原始响应雨量、32,188,520网格端点、26,351,104个已建模道路值、16个输入SHA、57个输出SHA及58个ZIP文件。最大独立基准重放误差5.92e-8 m（float32归档）；8组全域累计水量残差最大1.43e-6 m³。

180→60 s内部时间步最大道路端点差0.023146 m；按本原型的绝对0.02 m＋峰值5%容差通过，这不是高精度水动力收敛证明。5→10 km外扩最大道路端点差0.039351 m。图中网格峰值可来自不同时刻，面积只按150 m像元估算；没有模拟像元内部分淹没。

DSM含建筑与植被，不是裸地DTM；最大地形洼地储量阈值约29.38 m，可能混有DSM及聚合伪洼地，不能当作真实洼地深度。固定D8树、逐格储量和合并损失只构成简化汇流，没有二维动量、回水、管网或动态流向；干初始条件和小时内均匀降雨均为假设。未接入站点水深校准，未更新交通速度/容量、分配、韧性或SUMO。
