# 龙岗暴雨内涝情景阶段报告

2026-11-18完成龙岗不含大鹏的合成道路网格积水情景。当前运行：`data/synthetic/longgang_storm/20261118T124853_longgang_storm_7e7668c1`。

方法定位为“合成道路低点＋合成降雨驱动的动态积水假设”，更接近方案A的参数化扩展，但没有已核实历史积水点。没有实现B的地表汇流或C的管网二维耦合，不能用于真实积水预测。逐步方法、公式、参数与输入输出见[LONGGANG_STORM_MODEL.md](LONGGANG_STORM_MODEL.md)。

## 规模与范围

沿用龙岗OD边界，按不超过100 m道路间距采样33,597点，地形无缺测，250 m道路网格内选出4,139个合成低点代理。7,800个接受的源道路要素中，6,848个参与地面积水模型，952个桥隧或非零layer保持未建模NaN。

从既有推定OD图读出86,807条有向弧的精确保存ID与u/v/key，426条跨研究边界弧单独标记；图拓扑本身仍未认证。源线暴露取其所有关联代理水深最大值，是偏保守的几何关联，不是实测整条路水深。

## 验证

141项测试通过，56条Rasterio/Affine待弃用警告，pip check无冲突。17项运行检查通过。区间/事件水量平衡最大误差为1.847e-13/1.819e-12 mm。所有代理点边界偏差最大2.181e-10 m，仅允许1微米数值容差。

独立审计覆盖20组共8,029,660个单元端点值，逐项复核降雨、水量递推、无雨离散闭式解及道路最大值聚合；复核104个输入输出SHA和ZIP内93个文件。道路聚合最大误差0，递推误差2.220e-16 m。

5分钟复核将原15分钟雨量均分，三档共同端点最大差异0.00394/0.00813/0.01232 m。这是数值敏感性结果，不能代替实测校准或证明连续解收敛。图像PNG已逐张查看，SVG留在本地运行包。
